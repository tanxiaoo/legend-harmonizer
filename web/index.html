Legend Harmonizer

Compare two land-cover legends via per-class GMMs and Bures–Wasserstein affinity. Set the shared parameters, then add one or more AOIs — draw a rectangle on a map, upload a boundary, or type a bounding box on its card. Each card's Sample points button only collects that AOI's points from GEE; Run all AOIs fits the per-class GMMs and computes the affinity + crosswalk from the cached points. The primary AOI carries the main comparison; every other AOI is an auxiliary covering classes the primary lacks.
